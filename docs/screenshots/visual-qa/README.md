# Visual QA

Проверено локальным Playwright/Chromium при `1440×900` и `390×844`.

## Итог

- 11 основных страниц × 2 viewport: HTTP-ошибок и переполнения корневого layout нет.
- Dashboard chart имеет ненулевой canvas в обоих размерах.
- Создан и завершён run, открыта операция `op_103`.
- Ошибка пустой очереди показана как ожидаемый `422` с читаемым сообщением.
- Strategy Lab показывает 4 результата сравнения.
- Generator preview показывает 20 операций; bundle скачивается с ожидаемым именем.
- Пустые Dashboard и Runs проверены на отдельной временной SQLite без изменения рабочей базы.
- Единственные события, отмеченные браузером как ошибки: ожидаемый `422` валидации и `ERR_ABORTED` навигации при успешном download.

## Артефакты

- `final/report.json` — измерения страниц, canvas, overflow и browser events.
- `final/empty-report.json` — проверка пустых состояний.
- `final/mobile-states-report.json` — мобильные формы и доступность всех ссылок навигации.
- `final/desktop-*.png`, `final/mobile-*.png` — итоговые полноразмерные снимки.
- `baseline/` — снимки до исправления адаптивности.
